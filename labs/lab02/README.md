2. Структура вхідних даних (data/)

Для роботи Завдання 2 використовуються файли з каталогу data_v08 архіву lab2_data.zip:

    labs/lab02/data/dns_queries.csv — вхідний журнал DNS-транзакцій (містить поля Timestamp, ClientIP, Domain, QueryType).

    labs/lab02/data/blacklist.txt — локальний перелік заборонених фішингових та шкідливих доменних імен.

    labs/lab02/data/dns_alerts.csv — автоматично згенерований звіт з виявленими інцидентами.


3. Команди

   Команда 1: Запуск Завдання 1 (демонстрація ООП)   
   python -m labs.lab02.main demo
   Команда 2: Запуск Завдання 2 (аналіз DNS через головний файл) 
   python -m labs.lab02.main analyze --dns-log labs/lab02/data/dns_queries.csv --blacklist labs/lab02/data/blacklist.txt
   Команда 3: Або запуск модуля task2 безпосередньо 
   python -m labs.lab02.task2 --dns-log labs/lab02/data/dns_queries.csv --blacklist labs/lab02/data/blacklist.txt


4. Опис параметрів командного рядка (CLI)

    --dns-log (обов'язковий): шлях до CSV-файлу з журналом DNS-запитів.

    --blacklist (опціональний): шлях до текстового файлу чорного списку (за замовчуванням labs/lab02/data/blacklist.txt).

    --out-csv (опціональний): шлях для вивантаження виявлених загроз (за замовчуванням labs/lab02/data/dns_alerts.csv).

    --min-domain-len (опціональний): поріг аномальної довжини домену для виявлення DGA/тунелювання (за замовчуванням: 30).

5. Поведінка системи при помилках та валідація

    Помилка валідації Email: якщо пошта не відповідає регулярному виразу, клас User генерує ValueError.

    Відсутність вхідного логу: якщо шлях до лог-файлу не існує, утиліта фіксує [ERROR] через logging і завершує виконання з кодом виходу 1.

    Відсутність чорного списку: якщо файл blacklist відсутній, утиліта не падає, а виводить попередження [WARNING] та продовжує евристичний аналіз.

    Некоректний ключ облікового запису: звернення до невідомих ключів у UserAccount[...] викликає KeyError.
